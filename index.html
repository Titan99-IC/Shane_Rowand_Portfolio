Axle Platform Overview

A hub-and-spoke architecture AI platform designed for extensibility and modular integration. The core system manages multiple specialized subsystems and provides unified control, monitoring, and orchestration across diverse hardware and software components.

Architecture Highlights:

  • Hub Layer: Central orchestration engine handling task routing, resource allocation, and state management
  • Spoke Connectors: Modular interfaces for hardware integration (robotics, sensors, actuators)
  • AI Engine: Machine learning pipeline for perception, decision-making, and autonomous control
  • Communication Protocol: Standardized message passing for inter-component coordination

Hexapod Robot

A six-legged locomotion platform extending the Axle ecosystem with physical presence and manipulation capabilities. Designed for autonomous exploration, navigation, and interaction with dynamic environments.

Key Features:

  • Modular leg design with servo actuation
  • Gait planning algorithms (tripod, ripple, wave)
  • Integrated sensor suite (IMU, camera, distance sensors)
  • Real-time kinematics computation

Woodworking & Resin Art

Combining traditional woodworking with modern resin casting techniques. This project showcases precision craftsmanship and materials science, including both the Spotify Barcode series and custom resin furniture pieces.

Seatbelt Tracker

An IoT-based vehicle safety monitoring system that tracks seatbelt compliance and passenger safety in real-time. Integrates with vehicle telemetry for comprehensive safety analytics.

System Components:

  • Embedded sensor nodes for seatbelt detection
  • Cloud-based data aggregation and analysis
  • Real-time alerts and compliance reporting
  • Integration with fleet management systems
